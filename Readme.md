# Whack-a-Mole Game 🎯

A simple interactive Whack-a-Mole game built using HTML, CSS and vanilla JavaScript.

## Features
- 30-second countdown timer
- Random mole appearances
- Interactive scoring system
- Multiple game holes
- Responsive layout
- Restartable gameplay

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Play
1. Click **Start Game**.
2. Click on the moles when they appear.
3. Each successful hit increases your score.
4. Try to achieve the highest score before time runs out!
